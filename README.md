## 📖 О проекте

**Student Messenger** — это веб-приложение для обмена сообщениями, разработанное на Python с использованием фреймворка **Flask** и базы данных **MySQL**. Проект реализует полный цикл взаимодействия пользователя: от регистрации до личного чата.

### ✨ Ключевые возможности:
- 📝 **Регистрация и Авторизация:** Система учетных записей с хранением данных в БД.
- 💬 **Личный чат:** Возможность переписки между зарегистрированными пользователями.
- 👥 **Список пользователей:** Интерфейс для выбора собеседника.
-  **История сообщений:** Сохранение переписки в базе данных MySQL.
-  **Дизайн:** Адаптивный и современный интерфейс.

# Как запустить проект

1. Открыть папку проекта в VS Code
2. Открыть терминал: меню Terminal → New Terminal
3. В терминале должно быть написано `(venv)` в начале строки — это виртуальное окружение
4. Написать команду и нажать Enter:
   ```bash
   python app.py
5. Открыть браузер и перейти: http://127.0.0.1:5000
6. Остановить сервер: нажать Ctrl+C в терминале
